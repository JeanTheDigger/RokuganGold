# 57.46a. Allied NPC Companion — Implementation Lock

Owner-approved 2026-06-06. s57.46 is the design source and is treated as LOCKED
as written; this file records the implementation scope and confirms the values
that the code consumes. Code: `simulation/companion_system.gd`,
`shared/companion_data.gd`.

## Scope (headless core)

`CompanionSystem` (pure class) + `CompanionData` (Resource) implement the
companion logic faithfully to s57.46: slots, the command interface, the AI
priority stack, morale, noise contribution, doshin rules, and death
consequences. All values are taken directly from s57.46 — nothing invented.

## Confirmed values (from s57.46)

- **Slots:** hard cap 6 (s57.46.2). City-doshin team = 1 slot; village doshin
  and named NPCs = 1 slot each.
- **Commands:** universal FOLLOW/HOLD/MOVE_TO/RETREAT; doshin add
  GUARD_EXIT/IDENTIFY/SEARCH_AREA; yojimbo add PROTECT; yoriki add INVESTIGATE;
  named ally = universal only (s57.46.5–8, .16). A BROKEN companion takes no new
  orders; a SHAKEN companion accepts only RETREAT (s57.46.4–5).
- **AI priority stack:** SURVIVAL (BROKEN → FLEE/RETREAT) > PLAYER_COMMAND >
  DEFAULT (FOLLOW). REACT is resolved in combat and does not change the standing
  command (s57.46.9).
- **Morale thresholds (fraction of starting companions lost):** village 0.30,
  city team 0.40, headman 0.50, yojimbo never; yoriki bushi-school 0.50 (Yu 7+)
  / 0.30 (else) and non-bushi 0.35; named ally by Yu 0.50 (7+) / 0.35 (4–6) /
  0.20 (1–3). SHAKEN at half the threshold (−5 combat); BROKEN at the threshold;
  morale does not un-break in-mission (s57.46.10).
- **Noise:** village 1.0, city team 0.5, headman 0.75; other companions reduce a
  +1.0 base by Stealth (1 → 0.5, 2 → 0.25, 3+ → 0). Party total is the sum
  (s57.46.13 worked example reproduced in tests).
- **Doshin rules:** teamwork +5 grapple at 2+ members (lost at 1); samurai
  avoidance (engage a samurai only with an active arrest warrant; village doshin
  also require the headman present); GUARD EXIT −10 vs a fleeing samurai
  (s57.46.3, .11).
- **Death:** doshin death increments settlement `doshin_losses`; named-NPC death
  is permanent → FILL_VACANCY + Tier 4 topic (s57.46.14).
