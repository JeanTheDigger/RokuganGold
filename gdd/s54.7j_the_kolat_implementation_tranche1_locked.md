# 54.7j The Kolat — Implementation Tranche 1 (LOCKED)

Owner-approved 2026-06-06. s54.7–s54.7i are the design source. This file records
the scope and confirmed values for the first implemented tranche: the headless
mechanical subsystems with explicit, unambiguous numbers. Code:
`simulation/kolat_system.gd`; data model on `L5RCharacterData`, `SettlementData`,
and the `KolatSect` enum.

## Data model added

- `KolatSect` enum completed (added JADE, ROC, STEEL).
- `L5RCharacterData` (all hidden, s54.7h): `is_kolat_master`, `special_data`,
  sleeper fields (`trigger_phrase`, `sleeper_command`, `conditioning_stability`

- `SettlementData.temple_vault_koku` (-1 = not the Hidden Temple), hidden.

## Confirmed values (from s54.7c/e/h)

- **Sleeper conditioning:** sessions = Willpower × 3; session = repeated contested
  Willpower (target) vs Temptation + Intelligence (Dream) until one side wins 3 in
  a row (Master → progress, target → session fails); completion installs the 4
  hidden fields, sets stability 100, and applies the −3.0 Honor cost once to the
  Dream Master (highest single-action Honor cost in the engine).
- **Stability:** starts 100; −5 per IC season untended; +10 on
  MAINTAIN_SLEEPER_CONTACT (capped 100, also resets contact-overdue). Not
  evaluated once activated.
- **Activation:** requires the exact trigger phrase, dormant, and stability > 50.
  Command ≤ 5 words.
- **Koku pipeline:** UNDERREPORT → `dirty_koku`; LAUNDER moves ≤ 5 koku/AP from
  `dirty_koku` → `kolat_koku`; TRANSFER `kolat_koku` → `temple_vault_koku`; Tiger
  allocation vault → `operational_koku`; vault minimum reserve 50.
- **Disruption:** SPONSOR_INSURGENCY 10 koku per Strength point;
  BRIBE_GARRISON_COMMANDER 5 koku/season ongoing; reserve checked before firing.
- **Dead-drop concealment:** rating 1–5; each visit past the 3rd in a season −1;
  0 = abandoned. Visit counter resets at the seasonal tick.
- **Eye contention:** one Master per IC day; resolve highest ImmediateNeed
  priority → Tiger wins ties → highest public Status.
