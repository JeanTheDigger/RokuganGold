# 54.7j2 The Kolat — Master Selection (LOCKED)

Owner-approved 2026-06-06. Kolat Tranche 2. s54.7a is the design source; this
file records the implementation and the queryable mappings of its tier criteria.
Code: `simulation/kolat_master_selector.gd`.

## Scope

`KolatMasterSelector.select_masters(npcs, dice)` performs the world-generation
Master selection faithfully to s54.7a: universal filters, per-Sect minimums,
weighted-tier draw (T1 ×5, T2 ×2, T3 ×1), fixed processing order as
conflict resolution, Sect skill boosts (max rule), and the hidden Master fields
(`is_kolat_master`, `kolat_sect`, `kolat_superior_id` — Tiger → -1, others →
Tiger's id). Returns KolatSect → npc_id (-1 = seat vacant).
`get_special_rule_flags()` surfaces the Sect special-rule seed values for the
world generator (Coin 2d10×10 hidden koku, Dream 1d6+2 sleepers, Silk 1d6+2
contacts).

## Confirmed values (from s54.7a)

- Universal filters: Insight Rank ≥ 3; not the Emperor; not already selected
  (one seat per NPC); must meet the Sect minimum skills.
- Tier weights T1/T2/T3 = 5/2/1; processing order Tiger → Chrysanthemum → Silk →
  Coin → Cloud → Jade → Dream → Lotus → Roc → Steel.
- Per-Sect minimums and skill boosts encoded exactly as the s54.7a tables.
- "What every Master receives": is_kolat_master, kolat_sect, kolat_superior_id,
  skill boosts (max rule). (is_unique, Dark Secret / Forbidden Knowledge / Spy
  Network / Perceived Honor advantages are applied by the advantage layer at
  world-gen — flagged, not duplicated here.)

## PROVISIONAL mappings (queryable proxies for role-based criteria)

The s54.7a tier criteria name specific roles/schools; these are mapped to
queryable character fields. Where the data model cannot express a criterion it is
relaxed to the Sect's skill thresholds (so the candidate still qualifies at a
lower tier rather than being excluded):

- Lord-tier ("has a province") → `role_position` contains Daimyo/Champion/Headman.
- Magistrate / Witch Hunter / Inquisitor → `role_position` / `school_name` substring.
- Clan/family/school-specific T1 entries → `clan` / `family` / `school_name` +
  `role_position` / `school_rank` checks (e.g. Yasuki Family Daimyo, Shosuro Actor R5).
- Dream T1 ("Head Sensei / senior Abbot / institutional access to isolated
  people") — no institutional-access field exists; relaxed to Temptation 5+ and
  Medicine 4+. PROVISIONAL.
- Steel T1 ("named ronin Glory 5+ / former Champion's yojimbo / Wolf Legion
  veteran") → Glory ≥ 5 + best weapon skill ≥ 5. PROVISIONAL.
- Roc has no profile (s54.7a) — generic eligibility, standard agent.

## Deferred

The Sect special rules' world mutation (creating the sleeper registry entries,
pre-placed Silk contacts, Master Cloud's spell/archive-location, Lotus/Steel cover
identities, the Tiger cross-identity map) are surfaced as flags / left to the
world-gen integration and later Kolat tranches. This selector decides WHO the
Masters are and stamps the core fields.
